# Deerhacks V Dashboard

A React-based network topology dashboard with real-time monitoring capabilities.

## Getting Started

### Installation

```bash
npm install
```

### Development

Run the development server:

```bash
npm start
```

The app will open at [http://localhost:3000](http://localhost:3000)

### Build

Build the production version:

```bash
npm run build
```

## Features

- Network topology visualization
- Real-time event feed
- Node inspector with telemetry
- Gemini AI integration
- Dark mode support

## Tech Stack

- React 18
- Tailwind CSS
